This project aims to predict the likelihood of customers leaving a service using machine learning techniques. By analyzing customer data such as age, balance, number of products used, and account activity, we can build a model that helps businesses identify at-risk customers and take proactive measures to retain them. Various models, including KNN, Naive Bayes, SVM, and Decision Tree, were tested and compared using metrics like accuracy, recall, F1-score, and ROC-AUC. 🚀📊
